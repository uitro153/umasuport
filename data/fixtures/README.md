# P0 가상 스냅샷

`p0.snapshot.json`은 데이터 계약과 한국 출시일 필터를 검증하기 위해 직접 작성한 **가상 fixture**다. 실제 캐릭터·스킬·상성·카드·대회·출시 일정의 정확성을 보장하는 자료가 아니다. `example.invalid` 출처도 실제 사이트를 가리키지 않는다.

- 두 인물과 세 의상으로 `baseId`와 `costumeId`의 관계를 확인한다.
- 서포트의 일반 힌트·이벤트·금색/하위 스킬 경로는 분리하며 획득 확률이나 수급 확정을 의미하지 않는다.
- 스킬 비용은 확인되지 않은 값 대신 `null`로 둔다. 가상 상성 `12`도 스키마 구조 검증용이며 상성 엔진의 검증된 정답으로 사용하지 않는다.
- 실제 이미지 파일이나 외부 이미지 링크는 포함하지 않는다.

2026-11-04 현재와 2027-02-10 가상 대회를 비교하면 다음 결과가 나와야 한다.

| 가상 서포트 | 현재 기준 | 대회 기준 | 판정 근거 |
|---|---|---|---|
| 현재 출시 카드 | 포함 | 포함 | 한국 확정 2026-10-01 |
| 미래 확정 카드 | 제외 | 포함 | 한국 확정 2027-01-15가 예상 2027-01-05보다 우선 |
| 대회 전 미래시 카드 | 제외 | 미래시로 포함 | 한국 예상 2027-01-20 |
| 대회 후 미래시 카드 | 제외 | 제외 | 한국 예상 2027-03-01 |
| 한국 일정 미확인 카드 | 제외 | 제외 | 일본 출시일만으로 한국 가용성을 판정하지 않음 |

실제 데이터 확보 후에는 원본을 별도 보관하고 정규화·출처 확인을 거쳐 새 스냅샷을 만든다. 회귀 테스트 재현을 위해 이 fixture는 실제 데이터로 덮어쓰지 않는다.
