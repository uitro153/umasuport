## 조사 근거와 분류

## 변경 범위와 검증

구현 수정 파일: **없음**. UI·CSS·게임 데이터·계산 점수·V1 계약은 수정하지 않았다.

테스트 수정 파일: 위 표의 17개 `.spec.ts`. 공통 보조 파일 `tests/e2e/p9-lineage.ts`를 추가했다. 이 보조 파일은 기존 V1 읽기/명시적 UI 가져오기/모브 포커스만 수행하며 localStorage로 앱 상태를 주입하지 않는다. 기존에 통과하던 테스트 본문은 작업 시작 시 사본과 정적 비교하여 변경되지 않았음을 확인했다. 테스트 개수도 유지했다.

Desktop은 수정한 대상만 먼저 선별 실행했다. 초기 재실행에서 더 뒤의 낡은 동선과 V1 예제 초기 상태를 발견해 해당 사례만 수정·재실행했다. Mobile은 Desktop 통과 후 같은 21개만 선택했다. 단순 타임아웃 증대로 실패를 숨기지 않았다.

검증 집계: **Desktop 21/21, Mobile 21/21 통과**. Desktop은 여러 선별 실행의 마지막 결과를 고유 사례별로 집계했으며 재시도 횟수를 더하지 않았다. Mobile은 같은 21개를 한 번에 선별 실행하여 4.8분에 모두 통과했다. 타입 검사·lint 통과. 전체 E2E 통과로 인증하지 않는다.
