## P8.7 실사용 흐름 정리 — 구현·회귀·화면 검수 완료

카드에서 캐릭터·의상 갤러리를 직접 열고 적인자 배지에서 종류·별수·고정을 별도로 편집한다. 상성·10종 시작 적성은 트리 위에 배치했다. 31인 설계는 PC 왼쪽 조작 패널/오른쪽 트리, 모바일 상단 설정 구조로 정리했다. 기술 검증 패널·내부 식별자 표시를 일반 UI에서 제거하고 필요한 미확인 안내는 짧게 남겼다.

사용자 검색은 캐릭터·의상·카드·스킬 이름과 별칭만 사용한다. DB ID는 검색하지 않으며, 검색 안내와 E2E 입력도 실제 이름으로 바꿨다. 개인 빠른 선택의 추가·삭제·정렬·기본 복원·새로고침 보존은 V1 밖의 로컬 환경설정이다. 기존 목표 5개 제한과 UUID·상성·배분·추천·저장 계약은 유지한다.

단위 601개/44파일·lint·TypeScript·계약·빌드가 통과했다. 이름 전용 검색 후 전체 E2E는116개 중110통과·6실패였으며, 고정 예제의 실제 번역명으로 입력을 맞춘 P3/P4 및 P8.7 재검증12개가 모두 통과했다. 사례별 대조에서 PC58·모바일58 모두 최신 통과 기록을 확인했다. 한 번의116개 무실패 실행으로 합산하지 않는다.

실제 PC·모바일 전후 화면과 PNG3종을 열어 검수했고, 618개 보호 파일·31개 UUID/부모 연결·개인 설정 변경 전후 V1 입력·159점·추천374+8=382/48목표/패시브8개를 확인했다. 실제 화면·원본 보존·실패 및 재실행 기록은 [P87_USER_FLOW_VALIDATION.md](P87_USER_FLOW_VALIDATION.md), 파일·로그 해시는 [산출물 색인](../.preview/p87-artifacts/README.md)을 따른다. P9 배포와 이미지 권리 승인은 이번 범위가 아니다.
