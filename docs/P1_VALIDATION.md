# P1 검증 범위와 실제 데이터 전환

기준: 2026-11-05 · 일본 원자료 연결, 한국 독립 기대값 미확보

준비 패키지는 별도 P1 참고 계약으로 연결했다. 일본 과거 상성쌍 9,180개 재현은 통과했으며, 한국 서버 7인/인자 기대값은 여전히 0건이다. 가상 규칙과 실제 자료를 혼합하지 않고 로컬 참고 모드에서 합산 기본 차단·인자 보정 대기를 적용한다. 최신 상태와 실행법은 `DATA_INTEGRATION.md`에 기록했다. 아래 가상 검증은 회귀 이력으로 보존한다.

## 현재 검증된 범위

P1의 5개 기능(7인 선택, 상성 합산, 빨간 인자 적성 변화, 후보 정렬, 조부 6배치)은 **가상 인물·가상 수치·가상 규칙**에서 검증했다. 이는 프로그램의 데이터 처리와 탐색 구조를 검증한 것이며, 한국 서버 게임 규칙이나 U-tools/GameTora와 일치함을 검증한 것은 아니다.

- 독립적인 작은 상성표의 수동 합산으로 총점 124 및 6배치 점수 `[124, 94, 84, 82, 72, 42]`를 검증한다.
- 상성표 누락과 명시적인 0을 구분하고, 형제 조부 슬롯 교환·부모 고정·인자 동반 이동을 검증한다.
- 인자 합계의 경계(0/1/3/4/6/7/9/10/12/13/15/16/18), 종류별 독립 합산, 기존 S 유지, 의상별 초기값을 검증한다.
- 미래시/확정/미확인 한국 출시일 필터, 별명·일문·의상명 검색, 추천의 결정론적 정렬을 검증한다.
- 1440px/375px 실제 브라우저에서 7인 편집, 인자 변경, 6배치 비교·적용, 기준일 변경, 분기 접기, 대화상자 Esc/포커스 복귀, P0 회귀를 검수한다.

## 실제 데이터 접속 절차

1. 작업 폴더와 `data/raw/`에 새로 확보된 자료가 있는지 확인한다. 없으면 상성표·적성 규칙·정식 이름·한국 출시일 중 필요한 항목을 사용자와 상의한다.
2. 원본을 보존하고 출처·확인일·적용 서버/패치를 기록한다. 인물/의상 ID와 상성 계산의 ID 단위, 같은 인물 배치 제한을 확인한다.
3. 실제 자료를 `data/snapshots/<버전>.json`으로 정규화하고, 계산 규칙도 `<버전>.rules.json`으로 분리한다. `data/fixtures/`는 회귀 테스트용으로 보존한다.
4. 실제 기본 상성 공식이 현재의 11관계 가중 합으로 표현되는지 확인한다. 다르면 엔진과 규칙 스키마를 확장한다. G1 보너스는 연결하거나 포함하지 않는다.
5. 자료 제공처와 독립적인 기대 결과를 아래 형식으로 채집한다. 가능하면 같은 입력을 U-tools·GameTora 등 두 도구에서 비교하고, 서버/패치 차이를 먼저 분리한다. 외부 사이트 코드나 이미지를 복제하지 않는다.
6. `tests/golden/`에 기대값을 직접 기록한 사례를 추가한다. 테스트 중 현재 엔진을 호출해 기대값을 생성하지 않는다. 본육성/부모/조부 의상 변경·동일 인물·적성 등급 경계·최적 조부 배치를 포함한다.
7. 스냅샷·규칙 검증과 골든테스트를 통과한 뒤 `src/data/pedigree-data.ts`의 두 import를 바꾸어 연결한다. `kind: verified`와 출처 상태는 실게임 확인 후에만 사용한다. 화면의 가상 표시도 데이터·규칙 상태에 따라 전환된다.

검증 명령:

```powershell
npx.cmd tsx scripts/validate/pedigree.ts data/snapshots/<버전>.json data/snapshots/<버전>.rules.json
npm.cmd run check
npm.cmd run test:e2e
```

## 독립 대조 사례에 남길 정보

| 항목 | 필수 내용 |
|---|---|
| 식별 | 사례 ID, 스냅샷 ID, 규칙 버전 |
| 출처 | 비교 도구명, 재현 URL/입력 기록, 확인일, 대상 서버·패치 |
| 7인 입력 | 각 슬롯의 인물·의상 ID, 인자 종류·1～3성 |
| 상성 기대값 | 중상작 이전 총점, 제공되는 경우 관계별 점수 |
| 적성 기대값 | 초기 등급·합계 별수·변경 후 등급 |
| 배치 기대값 | 6가지 묶음, 최고 배치와 동점 여부 |
| 판정 | 일치/불일치, 차이 원인, 수정한 규칙/엔진과 재검증 결과 |

현재 실데이터 대조 사례는 **0건**이다. 실제 자료가 없는 상태에서 참조 사이트와 일치한다고 표시하거나 임의의 게임 수치를 추가하지 않는다. PED-04의 계승 고유 확인·선택 반영도 실제 데이터가 없어 미구현이다.
