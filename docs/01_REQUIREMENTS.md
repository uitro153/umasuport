# 통합 요구사항 명세서 (SRS) v1.0

**프로젝트:** 한국 서버 우마무스메 인자 계보 설계·인자작 서포트 추천  
**기준일:** 2026-11-04 (Asia/Seoul)  
**사용 목적:** 개발 및 데이터 수집·검증·수용시험 기준. 의견 제안이 아니라 사용자 확정 요구를 우선 기재.

## 0. 목적·범위·용어

- 주 기능 A: 중상작 이전 **기본 상성**과 빨간 인자 적성 보정을 이용한 **인자 계보 설계**.
- 독립 기능 B: 선택한 **대회·각질에 공통으로 유효한 백인자 확보**를 위한 인자작 **서포트 6장 추천**, 종마 후보 보완.
- 사이트는 한국 서버 현재/미래시를 지원한다. 일본 서버 자료는 마스터 정보·연구 근거로만 사용하고 한국 서버 가용성을 별도로 판단한다.
- '범용': **선택 대회 내 동일 각질 여러 우마무스메에 공통 유효**. 다른 대회·각질 재활용을 의미하지 않는다.
- '핀포인트': 특정 우마무스메 또는 특정 경기 전개·가속 공백을 보완하려는 별도 목적.
- '계보 재활용': 기능 A의 깊은 혈통 유전자 배분에서 같은 가지에 인자를 집중해 종마 계보를 재사용하기 쉬운 성질. 기능 B의 범용 인자작과 혼동하지 않는다.
- '본육성 서포트': 최종 대회용 육성에서 사용하는 6장. '인자작 서포트': 백인자 목표 육성에 사용하는 별도 6장.
- '종마 후보': 백인자 목표 스킬을 습득하고 인자작할 수 있는 육성마. 실제로 그 백인자를 보유한 인자를 뜻하지 않는다.

## 1. 범위 및 제외 사항

### 1.1 반드시 구현

1. 계보 A의 7인 기본 및 31인 상세 계획, 기본 상성, 적성, 빨간 인자/선택적 유전자 자동 배분.
2. 서포트 B의 대회·각질·인자작 시나리오 입력, 본육성 서포트 고려, 스킬/6장 편성/종마 추천.
3. 한국 서버 기준 출시 타임라인과 미래 대회 시점 필터, 예상 일정 표시.
4. 계보·편성 저장/불러오기, 비교, 이미지 내보내기, 데스크톱/모바일 지원, 로그인 없는 운영.

### 1.2 범위 제외 — 금지할 기능 확장

- 중상작 G1 우승 **가산치 입력·합산·예상치**를 기본 상성 계산에 섞지 않는다.
- 출전 주자 1~3명 입력, 각 주자의 내장 스킬 조사, 자동/수동 인자작 선택을 요구하지 않는다.
- 육성 결과 스탯 예측, 완주율 시뮬레이터, 시나리오별 정밀 체급 점수화는 만들지 않는다.
- 인자화 확률을 스킬 가치에 곱해 서포트를 랭킹하지 않는다.
- 스킬의 다른 가속기와의 중첩 가능성만으로 인자작 목표 스킬을 감점하지 않는다.
- 일본 서버 미출시/기출시 여부를 한국 서버 출시 여부와 혼동하지 않는다.
- 외부 사이트의 코드/페이지 템플릿/게임 이미지를 승인·이용 조건 확인 없이 그대로 가져오지 않는다.

## 3. 기능 A: 계보 설계

### 3.1 계보 및 입력

| ID | 상세 요구 |
|---|---|
| PED-01 | 초기 화면: 본육성 대상 1, 부모 2, 조부모 4 = 7인 계보. 선택 전 빈 슬롯 사용 가능. |
| PED-02 | 각 슬롯의 캐릭터 선택: 이름·별칭 검색, 공식 한국어 표기, 동일 캐릭터의 의상 버전 식별. 각 슬롯의 적성/빨간 인자 표기. |
| PED-03 | 조합별 **중상작 이전 기본 상성**을 숫자로 표시하고 캐릭터 변경 시 갱신. G1 우승 보너스 계산 금지. |
| PED-04 | 상성에 유리한 부모/조부모 후보를 정렬·추천. **계승 고유** 확인 및 선택 반영. |
| PED-05 | 선택한 빨간 인자 종류/별수(개별 1~3성)와 각 세대 영향을 적용해 해당 육성 대상의 적성 등급 계산. |
| PED-06 | 목표·부모2·조부4가 모두 정해지면 부모 위치를 고정한 채 조부4의 부모별 배치 6가지 후보를 평가. 같은 부모 밑 두 슬롯의 교환은 중복 후보 아님. |
| PED-07 | 상세 보기: 7+증조 8+고조 16=31인 계보. 기본 화면에 31인을 강제 노출하지 않음. |
| PED-08 | 인자 분배는 수동 31슬롯 반복 입력을 요구하지 않는 **자동 추천** 우선. 사용자가 제약·목표를 바꾼 경우 재계산. |
| PED-09 | 조부모 인자작의 로테이션에 필요한 적성, 목표 빨간 인자를 생성할 A 이상 적성을 우선 충족. |
| PED-10 | 유전자작은 켜기/끄기 가능한 **선택적 목표**. 원하는 유전자 종류 선택. |
| PED-11 | 해당 조부모의 증조 2명+고조 4명에 배분한 동일 빨간 인자 별수를 기반으로 6성/12성 조건 비교; 다른 필수 조건에 영향 없으면 12성 우선, 그렇지 않으면 6성. |
| PED-12 | 동일한 충족 조건·총별수라면 한쪽 계보에 집중해 재활용할 수 있는 배분을 우대. **획득 확률 증가 효과로 오인 금지**. |
| PED-13 | 사용자 보유 완성 인자의 혈통은 임의 변경 불가능. 신규 설계용 인자와 보유/고정된 실제 인자를 구분. |
| PED-14 | 각 추천 결과에 상성, 적성 충족, 빨간 인자 배분, 유전자 조건 및 왜 다른 후보가 뒤처졌는지 표시. |

### 3.2 세대별 효과 범위 (필수 구현 검증)

- 증조부모(depth=3) 빨간 인자: 조부모 육성, 부모 육성에 직접 영향을 주는 세대 구간으로 모델링.
- 고조부모(depth=4) 빨간 인자: 조부모 육성 적성과 유전자 조건에 활용하며 부모 육성에 직접 영향을 준다고 계산하지 않음.
- 현재 계산 대상의 실제 부모/조부 인자 효과 범위 역시 게임 규칙 검증표/테스트로 고정.
- 육성마마다 잔디/더트 및 단거리/마일/중거리/장거리 적성이 다르므로 '모두 더트 A', '마일 B 이상' 같은 고정 기준 금지.
- 로테이션에 필요한 실제 목표 등급은 규칙형 옵션/프로필로 관리한다. 예시로 더트 D나 마일 C가 유용한 경우가 있어도 이를 전체의 상수로 지정하지 않는다.
- 목표 빨간 인자 적성 A 조건과 6/12성 유전자 조건에 관한 게임 내부 수치는 데이터 구축 때 참조 출처 및 테스트 케이스를 함께 기록한다.

### 3.3 조부모 6개 배치 계산 검수

- 부모 P1·P2와 조부 G1~G4 고정. {G1,G2} / {G3,G4}, {G1,G3}/{G2,G4}, …: 순서 없는 P1의 2명 선택 = C(4,2)=6.
- 부모 좌우가 고정되어 있는 조건이므로 서로 부모를 바꾸는 경우는 다른 후보임.
- 같은 부모 아래의 두 조부 슬롯 순서는 점수와 배분 가능성에 영향을 주지 않는지 검증하여 중복 제거.
- 완성 인자 고정 모드에서는 배치 교환을 계산으로만 제안하고 실제 혈통을 바꾸지 않는다.

## 4. 기능 B: 인자작 서포트 편성 추천

### 4.1 입력

| ID | 상세 요구 |
|---|---|
| REC-01 | 구체적인 한국 챔미/말오스 대회 선택: 코스·거리·방향·계절·주로 조건 자동 연결. |
| REC-02 | 각질 1개 선택(도주·선행·선입·추입). 대상 육성마 지정은 기본값/필수 입력이 아님. |
| REC-03 | **인자작에 사용할 시나리오** 선택. 시나리오별 핵심 링크 카드가 있는 경우 우선 슬롯 후보로 적용. |
| REC-04 | 본육성 서포트 6장을 설정해 이미 안정적으로 얻는 스킬과 인자작 필요 스킬 비교. 미완성 설정에서도 기본 추천은 가능하되 수급 역산 정보 부족 표시. |
| REC-05 | '균형 우선 / 스킬 수급 우선 / 육성 안정성 우선' 드롭다운 제공. 세 항목은 **동일한 유효 스킬 집합**에 대한 편성 선호만 조정. |
| REC-06 | 보유 서포트·돌파 필터 사용 가능. 미등록 카드도 전체 DB 추천을 볼 수 있음; 대여 한 장 가능 여부는 편성 구성에서 명시. |
| REC-07 | 자동 추천 핵심 스킬 목록을 보면서 사용자가 특정 스킬을 우대/제외 또는 필수 목표로 조정할 수 있음. 핀포인트 목적은 이 방식으로 지원. |

### 4.2 스킬 가치와 추천 방향

| ID | 상세 요구 |
|---|---|
| REC-08 | **해당 대회×각질에 여러 육성마가 공통 사용 가능한 스킬**을 기본 평가 범위로 선정. 다른 대회 재활용에 기본 보상 주지 않음. |
| REC-09 | 마신 효율·유효율·스킬Pt 가성비를 우선 기준으로 사용. 근거 없는 마신/발동률 숫자 생성 금지. |
| REC-10 | 대체하기 어려운 핵심 스킬은 보존. 가속기 중첩 우려로 인자작 대상에서 자동 감점 금지. |
| REC-11 | **시계방향·계절류 등 저렴한 스피드 녹딱 우대**. 스태미나 패시브도 적극 고려; 비싼 '자신감'류는 겸사겸사 획득 정도로 후순위. |
| REC-12 | 녹딱은 선택 대회 조건에서 실제 발동 가능한지 확인. 날씨·마장 상태가 불확정이면 확정이라고 표시하지 않음. |
| REC-13 | 본육성 6장으로 얻을 수 있어도 인자작 목표에서 기계적으로 제거하지 않음(추가 힌트 효용). 안정적인 고레벨 힌트는 상대적 우선순위 조정 가능. |
| REC-14 | 일반 힌트/이벤트/금색 스킬 및 하위 백인자 경로를 구분해 표시. 단순 '카드 보유 스킬 전체=확정 수급' 가정 금지. |
| REC-15 | 실제 백인자화 **확률을 편성 점수에 곱하지 않음**. 힌트 접근성은 정성·경로 정보로만 반영 가능. |

## 5. 시간/한국 서버 미래시 (공통·중요)

| ID | 상세 요구 |
|---|---|
| TIME-01 | 콘텐츠별 일본 서버 출시일·한국 서버 확정일·한국 서버 **예상일**을 별도 필드로 보유. |
| TIME-02 | 구체 대회를 선택하면 **기본값: 그 대회 시작 시점의 콘텐츠 목록** 적용. |
| TIME-03 | '현재 시점 기준'으로 전환 가능; 미래 대회라도 지금 확보 가능한 카드만 확인할 수 있음. |
| TIME-04 | 한국 확정 출시일이 목표 기준일 이하인 콘텐츠 포함; 이후 콘텐츠는 제외. |
| TIME-05 | 한국 확정 출시일이 없고 미래시 예상 출시일만 있으면 목표일 이하일 때 **예상 콘텐츠로 포함**, 추천 결과에 '미래시/변동 가능' 명시. |
| TIME-06 | 실제 출시일이 확인되면 확정값이 예측값보다 우선. 추측만 있고 합리적인 날짜 매핑 자체가 없으면 자동 포함하지 않음. |
| TIME-07 | 패치에 따라 바뀐 스킬·서포트 효과는 해당 목표 시점에 유효한 버전 선택. |
| TIME-08 | 대회 자체가 예상 일정이면 '예상 대회' 표시, 목표 기준일은 해당 대회의 예상 시작일 사용. |
| TIME-09 | 한국 날짜와 시간대는 Asia/Seoul. 대회 진행 중 신규 출시 카드를 무턱대고 시작일부터 가용하다고 취급하지 않음. |

**일정 판정 예시(가상):** 오늘 11월 4일, 대회 2월 10일, 카드 출시 확정 1월 15일→대회 기준 포함/현재 기준 제외. 출시 예상 1월 20일→대회 기준 포함하며 '미래시' 표기. 출시 예상 3월 1일→둘 다 제외.

## 6. 데이터/자산/저장 요구사항

- 한 게임 개체에 고유 ID: `character_base_id`(기본 인물), `costume_id`(육성 의상 버전), `support_id`, `skill_id`, `event_id`, `scenario_id`, `course_id`.
- 등장 이름은 한국어 정식명/일어 원문/별칭을 별도 관리. 동일 캐릭터의 의상별로 포트레이트가 바뀌어도 인물 일치 검증 가능.
- 서포트 정보는 타입, 희귀도, 카드 주인, 돌파·힌트, 일반 힌트, 이벤트, 금색/하위 경로, 링크 적합도를 구분.
- 마신 데이터는 해당 경기장·각질·전제·분석 시점과 출처를 함께 저장. 미검증이면 공란/등급 평가 사용.
- 계보·편성 저장 파일은 버전과 데이터 스냅샷 ID를 포함하고, 이전 저장본 마이그레이션을 지원.
- 이미지는 공식 게임 아트 또는 제3자 배포 자산의 권리 확인 전까지 **플레이스홀더**를 기본으로 사용. 승인 없는 외부 서버 hotlink 금지.
- 정적 호스팅에서 JSON 데이터와 코드가 공개될 수 있으므로 로그인 없는 공개 도구에 비밀 키를 번들링하지 않음.

## 7. 화면과 접근성

- 상단: 메인 계보 / 서포트 추천 / 저장 설계 전환. 도구별 주요 액션은 눈에 잘 띄게.
- 계보 데스크톱: 중앙 7인 트리 / 우측 요약·후보·조건 패널. 상세 31인은 분기별 접기/확대.
- 모바일: 상단 요약 → 부모 A/B와 각각의 조부 2인 분기 접기; 31인을 가로로 축소해 한 장에 욱여넣지 않음.
- 카드: 작은 초상, 짧은 이름, 의상 버전, 적성, 빨간 인자, 상성 기여를 필요한 깊이에서만 표시.
- 서포트 추천: 대회·각질·시나리오·추천 성향은 드롭다운, 6장 편성 슬롯 + 핵심 스킬·이유.
- 탭 이동, 키보드 포커스, 색상만으로 적성/희귀도 전달하지 않기, 터치 영역 충분히 확보.

## 9. 명시적 미확정 사항 (추측하지 말고 데이터 확보 때 처리)

- **상성표 원본 및 계산식**: 어떤 ID 단위로 작동하는지/의상별 처리 여부/동일 인물 관련 규칙을 검증용 입력·출력 사례로 고정.
- **빨간 인자·유전자 정확한 규칙**: 세대별 적성 반영, 각 유전자 성수와 실제 조건을 검증 데이터로 잠금. 사용자에게 이미 합의된 12성 우선/6성 대안을 다시 물어보지 않음.
- **서포트 시나리오 링크 표**: 실제 시나리오/카드 데이터로 확정. SR 과다의 정량 페널티는 데이터가 없으면 작은 주의 문구만 사용.
- **대회별 마신 효율**: 출처·시뮬레이션 조건이 없는 항목은 등급/수급원으로 평가. 임의 숫자 금지.
- **게임 이미지 재사용권**: 공식 권리/제3자 호스팅 권한을 확인하기 전에는 배포하지 않음.

결론: 위 미확정 사항은 새로운 기획 회의가 아니라 **데이터 수집 및 테스트 작업 항목**이다. 이 문서를 기준으로 바로 구현을 시작한다.
