# P8.7.2 실사용 결함 수정

확인일: 2026-11-06 (Asia/Seoul). P9 배포·전체 회귀는 수행하지 않았다.

| 항목 | 실제 원인과 수정 결과 |
|---|---|
| 다크 가독성 | 8자리 반투명 흰 배경과 일부 밝은 배경이 기존 팔레트 변환 밖에 남았다. 배경·본문·보조·비활성·강조색을 정리하고 정보 버튼/서포트 상태를 다크 표면으로 변경했다. 대표 실측 텍스트 대비 최저6.07:1. |
| 적인자 직접 편집 | 배지의 핸들러가 계속 상세 편집창을 열었다. 7/31인 카드 하단을 직접 선택 컨트롤로 바꾸고, 별수·실제 기록 상세도 모달이 아닌 페이지 영역으로 변경했다. 새 계획은3성, 기존 개체의1/2성은 유지한다. |
| 31인 자동 배분 | 엔진은 빈 조상을 처리했지만 UI에서 목표 없음·0변경·오류를 구분하지 않았고 결과/실패 안내도 작업 위치에서 멀었다. 목표 확인·진행·예외·0변경 안내를 버튼 바로 아래에 두고 변경 목록을 펼쳤다. 기존 탐색/점수/잠금 정책은 그대로다. |
| 빠른 선택 저장값 | 예전 저장 목록을 그대로 읽어 자동 기본값5개도 유지됐다. 정확히 동일한5개·순서·편집 표시 없음만 한 번 정리하고, 개인 목록과 명시적 편집 기록은 보존한다. 같은 로컬 키의 환경설정 형식2에 편집 표시를 저장한다. P8 V1 및 실제 목표는 별개다. |

**실제 배분 사례:** 검증용 사용자 입력으로 대상 다이와 스칼렛, 부모 엘 콘도르 파사/오구리 캡, 조부 미호노 부르봉/타이키 셔틀/마루젠스키/토카이 테이오를 선택했다. 조부 A1 미호노 부르봉의 단거리 생성 목표, 부모 B 혈통 고정, 증조·고조24개의 캐릭터/인자는 모두 빈 상태로 실행했다. 기존 공개 보정식의 단거리 C→A에 필요한4성이 **고조3 단거리★1·고조4 단거리★3**, 총2개 계획 노드로 제안됐다. 취소 시 원본 유지, 적용·V1 재가져오기 후 표시,7개 UUID·모든 부모 연결·고정 혈통 유지와 새 실제 개체 미생성을 확인했다. 한국 서버 실물 인자 인증 사례가 아니다.

**검증:** 집중 단위4사례, PC·모바일 핵심4사례를 확인했다. 서포트·스킬 대비 및 별수 상세/목표 없음 안내를 보완한 해당 사례만 추가 확인했다. 대표 갤러리/상세6.07 이상, 계보7.79 이상, 배분8.58 이상, 스킬8.76 이상, 서포트/상세8.58 이상이었다. 실측은 브라우저가 계산한 텍스트/배경 조합 기준이며 사이트 전체 접근성 인증은 아니다. 타입·lint 통과. 전체601개 단위/116개 E2E·빌드·벤치마크는 이번에 실행하지 않았다.

주요 파일: `src/ui/p872.css`, `theme-palette.css`, `lineage/UnifiedLineageTree.tsx`, `LineageNodeEditor.tsx`, `LineageDesigner.tsx`, `skills/quick-skill-preferences.ts`, `SkillPrioritySettings.tsx`. 배분 엔진 변경은 실패 안내 문구뿐이다.
