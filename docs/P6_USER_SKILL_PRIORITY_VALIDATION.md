# P6 — 사용자 지정 스킬 우선순위·맞춤 추천 검증

> [P7 계보·백인자 통합](P7_LINEAGE_SKILL_INTEGRATION_VALIDATION.md)은 아래 P6 정책을 유지하며 소유 노드별 사용자 정보와 명시적 목표를 연결한다. 현재 인자작/미래시, 전역/노드 목표와 최종 본육성 덱의 수급 경로는 별도로 구분한다.

> 후속 [P6.1 기존 편성 비교·탐색 감사](P61_SEARCH_OPTIMALITY_AUDIT.md)에서 기존 P4.1 6장과 P6 혼합6장을 같은 조건으로 재평가했다. 모두382점이며 현행 균형 동률 기준상 공급 중복이 적은 P6 편성이 우위다. 엔진·정책·아래 P6 결과는 변경하지 않았다.

기준일: **2026-11-05**, 프로젝트: `C:\dev\UMA`.

기존 P5 기본 추천과 게임 데이터를 유지하고, 최대 5개의 일반 백인자 목표에 사용자 선호를 별도로 적용했다. 실제 P3/P5 DB 기반 맞춤 요청 **32사례**, 기본 추천 3대회 회귀, 소규모 독립 조합 정답 및 배타 이벤트 단위 검증과 **PC·모바일 브라우저 54개**를 통과했다.

작업 전에 [P4_SUPPORT_OPTIMIZATION.md](P4_SUPPORT_OPTIMIZATION.md), [P41_RECOMMENDATION_QUALITY.md](P41_RECOMMENDATION_QUALITY.md), [P5_INTEGRATION_VALIDATION.md](P5_INTEGRATION_VALIDATION.md), [P5_RECOMMENDATION_POLICY.md](P5_RECOMMENDATION_POLICY.md), [P4_QUANTITATIVE_DATA_CONTRACT.md](P4_QUANTITATIVE_DATA_CONTRACT.md)를 확인했다. 기존 데이터를 재수집하거나 추천용 게임 데이터를 생성하지 않았다.

## 1. 신규 UI와 사용 방법

기존 인자작 서포트 추천 영역의 **스킬 우선순위 설정**을 펼쳐 사용한다.

1. 한국어 이름 또는 기존 스킬 ID로 검색하고 목표를 선택한다. 한국어명이 없으면 일본어명을 표시하며, 검색 결과에 원본 ID를 함께 표시한다.
2. 선택한 각 목표를 **우선 확보 / 강력 우대 / 필수 확보**로 설정한다. 최대 5개이며, 개별 삭제와 전체 초기화를 지원한다.
3. 설정 변경 후 300ms 지연 재계산 또는 **우선순위 적용 후 추천** 버튼으로 계산한다. 초기 0개 상태는 기존 기본 추천만 계산한다.
4. 기본·맞춤 6장, 세 점수, 지정 목표의 공급 카드, 녹딱 수, 양립 가능한 목표 수, 얻고 잃는 스킬을 비교한다. 양쪽의 후보·상태·빔·이벤트 계획·최적성 범위도 함께 표시한다. 카드 상세에서 원본 힌트·이벤트·금색 하위 경로와 선택 분기를 확인한다.
5. **기본 추천으로 돌아가기**로 선택을 초기화한다. 대회·각질을 변경하면 선택은 유지되며 새 조건의 비해당·미검증·출시 경고를 갱신한다.

빠른 선택은 실제 ID와 일본어 원명을 대조한 터다지기 `201601`, 포지션 센스 `200452`, 위험 회피 `201262`, 교묘한 스텝 `201332`, 집중력 `200432`만 제공한다. 사용자가 누르기 전에는 평가를 바꾸지 않는다.

Worker에 요청 서명을 전달하고 현재 스냅샷·대회·설정과 다른 응답을 표시하지 않는다. 실행 중 입력이 바뀌면 이전 Worker를 종료하고 새 요청을 계산한다. 로딩·오래된 결과 안내를 유지했다. 모바일에서는 검색·선택·비교를 세로로 배치한다. 이 동작의 최종 브라우저 검증 상태는 10절에 별도로 기록한다.

직접 지정한 비해당·미검증 일반 목표도 선택할 수 있다. 화면의 **양립 가능한 일반 목표**는 그런 사용자 목표를 포함할 수 있으므로, 기본 평가와 경고를 함께 표시한다. 목표 수가 증가했다는 사실만으로 게임상 유효성이 검증되었다고 표현하지 않는다.

## 2. 우선순위 정책과 점수 적용

| 등급 | 적용 | 의미 |
|---|---|---|
| 우선 확보 `preferred` | 수급 계획에 포함된 목표당 +8 | 사용자의 완만한 선호 |
| 강력 우대 `strong` | 목표당 +24 | 다른 일반 목표와 교환할 수 있는 선호, 확보 보장 아님 |
| 필수 확보 `required` | 가산 0, 편성 조건 | 같은 6장·양립 계획에 모든 필수 목표의 수급 기회 필요 |

`맞춤 평가 점수 = 기존 기본 정성 점수 + 중복 없는 사용자 선호 보너스`다. 8/24는 사용자 정책값이며 마신·발동률·백인자 생성률이 아니다. P5의 기존 정성 평가 16/10/8/6/2와 녹딱·공략 참고 정책은 변경하지 않았다. UI에서 기본 정성 손실을 별도로 표시한다.

여러 카드가 같은 목표를 공급해도 커버리지와 사용자 보너스는 한 번만 합산한다. 기존 명시적 `lower_skill` 관계로 확인되는 ○·◎ 및 금색 하위 계열만 동일 일반 목표로 정규화하고, 중복 선택은 사용자가 정한 가장 높은 등급 하나로 합친다. 실제 `201321`·`201322` 중복 선택은 가산 24 한 번이었다. 금색 `201602` 선택은 확인된 일반 하위 `201601`로 안내하며 금색 자체를 백인자 목표에 넣지 않았다.

이름 유사성·일반 `variant`·숫자 접두어로 ID를 추정하지 않는다. 미연결·복수 하위·순환 관계는 보류한다. 고유·진화·계승 전용은 제외하며, 희귀도 1인 실제 계승 스킬 `900011`도 `inherited_version` 관계로 차단하는 회귀를 추가했다.

비해당·미검증 목표의 기존 기본 점수는 계속 0이다. 사용자 선호 또는 필수 조건이 그 목표를 객관적으로 유효한 스킬로 승격하지 않는다. 한국 적용 인증 정량값은 **0건**이며 U-tools 참고 수치를 점수에 적용하지 않았다.

## 3. 필수 확보 조건의 구현

필수 목표를 비트 마스크로 표현하고, 실제 카드별 양립 이벤트 계획을 사용한다. 힌트는 해당 카드의 실제 경로여야 하며, 이벤트는 관련 그룹 모두에서 선택한 분기가 원본 보상을 제공해야 한다. 같은 이벤트의 배타 선택지·성공과 실패 보상을 합집합으로 충족 처리하지 않는다.

동일 인물 단위 동적 계획법(DP)이 **필수 목표 마스크·선택 카드 수·대여 수**를 검사하고 서로 다른 인물 6장의 수급 가능 증거를 만든다. 이를 정성 탐색의 초기 해로 사용할 수 있으나, 그 증거 자체를 점수 최적성 인증으로 취급하지 않는다. 최종 추천은 모든 필수 목표가 하나의 실제 양립 계획에 포함된 완성 편성만 반환한다. 부분 탐색에서 이미 확보한 필수 개수만 절대 우선해 좋은 후속 편성을 버리지 않도록 했다.

실제 터다지기 필수 결과 376점은 이미 발견한 강력 우대의 가용 편성 376점 이상이라는 하한도 검증했다. 기존 독립 기록 편성 374+24=398점과 같은 기준으로 비교했고 강력 우대 결과 400점이 그 하한에 도달했다. 특정 6장을 정답으로 맞추는 가중치 변경은 하지 않았다.

| 실패 코드 | 구분 |
|---|---|
| `no-released-source` | 현재 대회·출시 환경에 가용 공급 경로 없음 |
| `ownership-borrow-limit` | 보유·대여·동일 인물·6장 구성 제약에서 함께 충족하지 못함 |
| `mutually-exclusive-events` | 각 경로는 있지만 같은 이벤트 계획에서 양립하지 않음 |
| `search-limit` | 후보·빔·상태·이벤트 계획 또는 DP 한도로 판정하지 못함 |
| `unverified-source` | 원문 경로의 서버·분기·조건이 미검증이어서 확정할 수 없음 |

실패 시 `required-unfulfilled`와 빈 맞춤 추천을 반환한다. 기본 추천은 남기되, 빈 편성과의 가짜 얻음·잃음 비교는 생성하지 않는다. 한도가 있거나 미검증 분기가 남으면 전체 조합의 불가능 또는 배타 선택지라고 단정하지 않는다. 다섯 실패 유형, 독립 소규모 전수 조합 정답, 배타 이벤트 및 다른 카드 공급을 이용한 재계획은 단위 사례로 검증했다. 이 합성 단위 자료를 실제 게임 DB의 이벤트 실측으로 표시하지 않는다.

**필수 확보는 수급 기회를 요구한다. 힌트 발생·이벤트 완주·성공·백인자 생성·계승 성공을 보장하지 않는다.** 실제 DB 검증의 모든 편성은 획득 보장 목록이 비어 있고, 이벤트 확률은 `null`이다.

## 4. 지정 스킬 공급 카드와 후보 탐색

기존 P3/P5의 출시 판정·수급 어댑터를 재사용한다. 한국 확정·2차 근거·일본 미래시를 구별하며, 미래시 콘텐츠는 P5의 일본 콘텐츠 출시일과 대응 일본 대회일 순서를 따른다. 한국 예상 날짜로 일본 순서를 뒤집지 않는다.

기존 정성 기준으로 만든 기본 후보 최대 96장에 **선택한 목표의 가용하고 양립 가능한 실제 공급 카드**를 추가한다. 이후 보유·대여, 돌파, 동일 인물 중복 금지, 이벤트 계획 제약을 적용한 6장 탐색을 수행한다. 일반 힌트·이벤트·명시된 금색 일반 하위를 구분한다. 연구 목록에서 숨긴 명시적 ◎ 힌트도 직접 지정한 ○ 목표의 검증된 관계가 있으면 공급으로 인식한다.

원본 `source_unspecified`를 한국 확정 경로로 승격하지 않는다. 현재 한국 카드의 일본 전용 미래 패치 경로도 한국 공급으로 복사하지 않는다. 원스킬·금색·하위 스킬의 알려진 대회 후 출시를 사용자 선호로 우회하지 않는다.

실제 터다지기 필수 사례는 기본 **96장 + 공급자 24장 = 120장**, 관련 공급 카드 29장이었다. 기존 96장 밖의 **니시노 플라워 [아침놀 딸기밭에서] `30208`**을 최종 채용했고 그 한국 일반 힌트 `201601`을 확인했다. 필수 수급 DP는 87상태에서 증거를 찾았으며 그 검사 한도에 도달하지 않았다. 선행 코너○는 96+10=106장, 두 목표 혼합은 96+34=130장, 도주 복수 필수는 96+20=116장이었다.

## 6. 위험 회피 + 포지션 센스

CM39 도주에서 위험 회피 `201262`와 포지션 센스 `200452`를 모두 필수로 지정했다. 도주 기본 364점에서 **362점, 양립 목표47개, 녹딱9개**의 편성을 찾았다. 선행 384점과 교차 비교하지 않는다.

- 편성: 나카야마 페스타30108·메지로 라모누30175·스마트 팔콘30017·사일런스 스즈카30252·에어 샤커30226·다이와 스칼렛30227.
