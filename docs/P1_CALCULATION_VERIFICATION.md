# P1 실계산 연결 검증

> **후속 적용:** 이 보고서의 검증 계산식을 변경하지 않고 실제 계보 UI에서 기본 활성화했다. 31인 상세 계보·혈통 재연결·자동 배분과 최신 회귀 결과는 [P2_LINEAGE_VERIFICATION.md](P2_LINEAGE_VERIFICATION.md)를 따른다. 아래 참고 모드 선택 설명은 이전 UI의 기록이다.

확인일: 2026-11-05 (Asia/Seoul). 원본 staging·KO·KR 자료와 P0 fixture는 수정하지 않았다.

## 확인 수준

- **구조/원자료 재현**: 기존 135인·272의상·9,180쌍 계약 유지.
- **공개식 외부 대조**: GameTora 실제 화면에서 7개 항목과 159점 확보. 로컬 계산 결과를 기대값으로 복사하지 않았다.
- **한국 서버 실측**: 0건. `snapshot.validation`의 세 pending과 JP 원자료 상태를 유지한다. 공개식 대조와 한국 서버 패치 동일성은 다른 주장이다.
- **빨간 인자**: 별도 `public-initial-red-stars-v1` 규칙을 실데이터에 적용한다. P0/P1 가상 규칙 팩을 재사용하지 않는다. 규칙 상태는 `public-supported-kr-pending`이다.

## 독립 기대값과 실제 비교

[GameTora 계산기](https://gametora.com/umamusume/compatibility)를 직접 조작했다. 페이지 표시는 **Global**이다. JP/KR 서버 인증으로 해석하지 않는다. 레이스·인자 입력은 모두 비어 있고 우승 보너스는 0이다.

| 슬롯 | 인물 / 기본 의상 ID |
|---|---|
| 대상 | 다이와 스칼렛 100901 |
| 부모 A | 엘 콘도르 파사 101401 |
| 부모 B | 오구리 캡 100601 |
| A1 / A2 | 미호노 부르봉 102601 / 타이키 셔틀 101001 |
| B1 / B2 | 마루젠스키 100401 / 토카이 테이오 100301 |

외부 화면의 점수는 대상–A 31, 대상–B 26, A–B 24, 대상·A·A1 22, 대상·A·A2 23, 대상·B·B1 15, 대상·B·B2 18이다. **31+26+24+22+23+15+18=159**, 로컬의 모든 항목과 일치한다. 기본 합산은 한국 실측 대기 때문에 기존처럼 꺼져 있다. 참고 비교를 켜면 이 공개식으로 실제 자료의 후보·배치를 정렬한다.

기대값은 `tests/golden/public-expectations.json`, 실제 원자료 발췌는 `tests/golden/real-reference-subset.json`에 고정했다. 발췌본은 원본 manifest와 출처를 보존한다. 공개 계산기와 수집 DB의 상위 데이터가 독립인지 확인하지 못했으므로 독립 데이터셋 두 개로 세지 않는다.

## 발견한 불일치

[U-tools 엄밀판 설명](https://xn--gck1f423k.xn--1bvt37a.tools/announcements/4)은 2021-11-12 작성으로 표시된다. 다이와–오구리 24, 다이와·오구리·타이키 14를 제시하지만 준비 데이터는 각각 26과 15다. 현재 GameTora에서도 다이와–오구리 26을 확인했다. 따라서 과거 예시를 현재 golden 값으로 승격하지 않았다.

준비 자료의 교집합은 2인에서 `202:2, 2523:1, 3002:7, 3003:7, 3101:7, 3504:1, 3509:1`, 3인에서 `3002:7, 3101:7, 3509:1`이다. 역사적 변경 시점과 각 그룹 의미는 확인하지 못했으므로 불일치 원인을 패치로 단정하지 않는다. 실패했던 최초 대조를 역사적 불일치 기록으로 남겼으며 현재 일치 사례와 구분한다.

## 적성 보정

[GameWith 관측 표](https://gamewith.jp/uma-musume/article/show/270279)에서 1·4·7·10성에 1·2·3·4단계, 18성도 최대 4단계, 시작 A 상한을 확인했다. 이 글은 자체 확인·유저 제보 기반이며 공식 사양서가 아니다. [GameTora 계승 설명](https://gametora.com/umamusume/legacies)은 부모 및 조부모의 시작 보너스와 이후 계승을 구분한다.

선택된 부모·조부모 6명의 **동일 적성** 별수만 합친다. 대상 인자와 비어 있는 슬롯의 인자는 제외한다. 실제 기본 테이오 마일 E를 대상으로 0/1/3/4/6/7/9/10/12/18성의 표 기반 기대 등급을 검사한다. 기존 S 입력은 하향하지 않는다. 육성 중 S 획득 확률·인자 생성 가능성은 이 계산의 검증 범위 밖이다.

## 최대 6배치

부모와 대상 고정, A 쪽 조부모 두 명 선택 `C(4,2)=6`, 나머지는 B 쪽으로 배치한다. 같은 부모 아래 슬롯 교환은 동일 후보다. 같은 의상·같은 인자인 조부모가 반복되면 결과를 추가 중복 제거하여 1~6개를 반환한다. 서로 다른 인자 소유자는 보존한다. 동일 인물 사용의 게임 유효성 규칙을 새로 확정한 것은 아니다.

검증은 별도 24개 전순열 열거 및 직접 교집합 oracle과 점수 목록을 비교한다. 이는 알고리즘 독립 검사이며 추가 외부 실측은 아니다. G1 가산·31인·서포트 추천은 추가하지 않았다.

## 한국 출시일

`src/data/reference-evidence.ts`의 추가 계층을 import 및 로컬 로드에 적용한다. 기존 원본 파일은 유지하며 출처별 `classification`, `publishedOn`, `releaseDate`, `checkedOn`, URL을 보존한다. 선택 카드에서 근거를 펼쳐 볼 수 있다. 기존 예측·미확인 필터는 그대로 유지한다. 미확인 날짜를 일본 출시 순서로 채우지 않는다.

- [카카오게임즈 공식 발표](https://www.kakaogamescorp.com/news/press/detail/1280): 2022-07-25 게시, 신의상 테이오와 맥퀸을 25일 추가했다고 명시. ID 100302/101302의 공식 확정일은 본문 근거로 2022-07-25.
- [인벤](https://www.inven.co.kr/webzine/news/?news=274505&site=uma): 2022-07-25 14:50 게시, 같은 두 의상과 해당 픽업을 확인. 2차 관측으로 별도 보존. 같은 기사에 나온 키타산은 서포트이므로 육성마 출시로 매핑하지 않는다.
- [나무위키 계열 테이오 문서](https://m.namu.moe/w/토카이%20테이오(우마무스메%20프리티%20더비)/인게임%20정보): 비욘드 더 호라이즌의 한국 출시 2022-07-25 일치. 미러로 접근했으며 게시/수정일은 확인하지 못해 null. 공식 출처로 승격하지 않았다.

공식 서비스 출시일 하나만으로 모든 초기 의상의 출시를 일괄 확정하지 않는다. 이번에 확인한 두 의상 외 나머지 한국 날짜는 기존 분류를 유지한다. 전수 출시일/공식 카페 업데이트 공지 대조는 잔여 과제다.
