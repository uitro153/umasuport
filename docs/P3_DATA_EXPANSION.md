## 한국 출시일

의상 272개는 기존 공식 확인 2개를 보존하고 **2차 자료 날짜 213개·미래시 57개**를 연결했다. 서포트 566개는 **2차 자료 날짜 469개·미래시 97개**다. 후자는 공식 날짜가 아니다. 기존 공식 확정 근거가 있으면 2차 자료로 덮어쓰지 않는다.

`release_ko`는 한국 원자료의 출시일 필드이며 일본·Global 출시일과 구별한다. 뽑기 첫 등장 연표와 향후 예측 파일을 함께 확보했지만 복각·기사 게시일을 최초 출시일로 복사하지 않는다. 미래시 파일 날짜가 과거더라도 확인된 출시일로 승격하지 않는다.

일부 스킬은 현재 한국 지역 수급 목록과 현재 출시된 카드의 교집합으로 **2026-11-05까지 존재한다는 2차 관측**만 기록한다. 카드 최초 출시일을 현재 스킬의 최초 출시일로 복사하지 않는다. 이 관측으로 과거 대회의 가용성을 소급하지 않는다. 스킬 자체 최초 출시일과 효과 개정일은 여전히 대부분 미확인이다.

## 파일과 실행

```powershell
cd C:\dev\UMA
npm.cmd run data:collect:p3
npm.cmd run data:import:p3
npm.cmd run data:validate:p3:local
npm.cmd run check
npm.cmd run test:e2e
npm.cmd run dev
```

`data:collect:p3`는 공개 원본을 실제로 내려받고, `data:import:p3`는 최신 수집본과 기존 원본 부분 집합을 합쳐 JSON·SQLite를 생성한다. 수집은 네트워크가 필요하고 변환은 로컬 실행이다. 원본 수집일이 바뀌면 스크립트의 기준일·표식·수동 근거도 재검토해야 한다. 단순 재실행만으로 새로운 기준일의 최신성을 인증하지 않는다.

- `data/raw/p3-2026-11-05/`: 새 다운로드 원본·해시·URL·실패 목록.
- `data/raw/p3-base-2026-11-04/`: 기존 ZIP에서 변환에 필요한 JSON·SQLite·manifest 부분 집합. 전체 ZIP 복제본이 아니다.
- `data/local/p3-skill-support.json`: 실제 화면이 읽는 고정 데이터.
- `data/local/p3-integrated.sqlite`: 원본 테이블과 신규 P3 테이블·전체 스냅샷. 신규 경로는 실제 SQL 외래키로 연결.
- `data/normalized/p3/coverage.json`: 수록·연결량·미확인 기록.
- `data/normalized/p3/jp-tournaments.json`: 한국 대회로 혼용하지 않는 일본 참고 일정.
- `data/local/p1-reference.before-p3.json`: 한국 날짜 보완 전 계보 데이터 보존본.

기존 단일 데이터 진입점·개발 전용 API를 재사용한다. 실제 전체 원본을 정적 배포 번들에 자동 포함하지 않는다. 공개 배포는 별도 단계이며 현재 P3는 로컬 개발 서버에서 동작한다. 기존 P3 임포터는 `data:import:p3:legacy`로 보존하되 기본 명령은 확장 임포터를 사용한다.

## 검증 및 완료 경계

기존 단위 테스트 320개와 추가 실제 데이터 테스트를 실행한다. 브라우저는 기존 34개와 전체 확장 데이터를 직접 읽는 PC·모바일 검사 2개를 실행한다. 골든 부분 집합을 이용하는 기존 회귀와, 모의 응답 없이 전체 데이터를 읽는 검사를 구별한다. 최종 단위 324개/24파일, PC·모바일 브라우저 36개 통과. 린트·타입·스냅샷 검증·빌드 및 SQLite integrity/FK 검사 통과. 이후 SQL 테이블 확장은 임포터의 무결성 검사로 재확인했다.

P3의 실제 데이터 기반 정성 평가·본육성 6장 경로 분석은 연결했다. 원본 스킬 효과와 공략 연구는 분리했고 마신·발동률은 임의 생성하지 않았다. 한국 과거 패치 재현, 전 이벤트 조건 완전성, LoH 연표, 전체 게임 데이터 수록률은 미완료다. P4 조합 탐색은 추가하지 않았다.
