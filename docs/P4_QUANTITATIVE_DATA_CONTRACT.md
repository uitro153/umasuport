# P4 정량 근거 계약

기존 `uma-p3-skill-support`를 변경하지 않고 `uma-skill-quant-evidence`, schemaVersion 1로 별도 저장한다. 자료량은 정확도나 한국 적용 가능성을 보증하지 않는다.

각 행은 canonical skillId, evidenceId, contextId, 출처 URL·해시, 원문 이름, 최소/최대/평균/중앙값/기대 마신, reportedActivationRate, effectiveRate, 선행 스킬 포함 비용 및 힌트 기준, 1Pt당/100Pt당 효율, 검토 상태를 갖는다. 스킬 변형과 다른 조건을 같은 행으로 합치지 않는다. 알 수 없는 수치는 null이며 0과 구분한다.

context는 서버·패치·계산기 버전·정확한 코스/각질/계절/날씨/마장·능력치/적성/의욕·출전 인원/상대·시행 방법/표본수·평가 분모를 명시해야 한다. source 기본 가정과 사용자 선택 입력은 구분한다. 입력 프로필과 서버 패치가 같은지 확인하기 전 대회 추천에 결합하지 않는다.

U-tools `r[4]`는 発動率이며 유효율이 아니다. 유효율에는 유효 구간·발동 위치 겹침 판정 및 분모를 별도로 정의한다. 기대 마신에 발동률이 이미 반영됐는지 확인하기 전 재곱하지 않는다. 출처 100Pt당 효율을 1Pt당 수치로 오해하지 않는다. 동일 힌트·선행 비용 기준에서 비교한다.

초기 자료는 모두 `rankEligible:false`. `getEligibleQuantEvidence`는 명시적 검토 승인, 양쪽 reviewStatus verified, 패치/버전/시행 방법/능력치/인원/날씨/계절/마장/표본수가 없으면 거부한다. 이 함수는 최소 유효성 검사다. 향후 평가 엔진 연결 시 대상 서버·패치·컨텍스트의 정확 일치도 추가로 확인해야 한다. 현재 P3/P4 추천 엔진은 이 참고 자료를 점수로 소비하지 않는다.

P4.1에서 `src/engine/quantitative-evidence.ts`의 `getEligibleQuantitativeEvidence`를 별도 평가 계층으로 추가했다. 수집용 최소 게이트와 구별하며 canonical 스킬 ID, HTTP(S) 출처·64자리 SHA-256, 위의 모든 프로필·방법·비용 조건이 대상과 정확히 일치해야 한다. 기대 마신의 발동 반영 여부가 확인돼야 통과하고 발동률·유효율을 재곱하지 않는다. 실제 1,993행은 승인 인자만 켜도 통과0건이며 추천 적용0건이다. 세부 검증은 [P4.1 보고서](P41_RECOMMENDATION_QUALITY.md)를 따른다.

v4.9.1 워크북은 읽기 전용 원본이며 캐시값을 신규 시행 결과로 쓰지 않는다. 현재 한국 환경을 승인하려면 적합한 버전의 계산식과 입력·표본·재현 절차를 검증해야 한다. 소스 버전 문자열만으로 최신 게임 대응을 인증하지 않는다.
