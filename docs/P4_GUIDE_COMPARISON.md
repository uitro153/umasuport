# P4 실제 공략 비교 근거

검토일: 2026-11-05. P3 확장팩의 2,223스킬·566카드·출시 469관측/97예측과 명시적 하위 관계를 재사용했다. 이 문서는 공략의 원래 주장과 비교 입력을 고정한다. 추천 결과·대체안의 실제 계산 보고는 별도 P4 검증 보고서에서 다룬다. 2023년 공략은 과거 사례이며 2026년 최신 전체 DB 인증에 사용하지 않는다.

## 결과가 다를 때의 검증 기준

- 공략의 6장을 정답으로 고정하지 않는다. 같은 대회·각질에서 추천 편성의 유효 스킬 합집합, 녹딱과 주요 누락, 교체 시 얻고 잃는 스킬로 비교한다.
- SR20003의 직선 주파200642 일반 힌트와 SR20033의 선행 코너201322 이벤트는 실제 팩에 존재한다. 이 경로가 사라졌다면 데이터/변환 오류를 조사한다. 해당 SR이 선택되지 않아도 대체 카드가 같은 스킬과 더 많은 유효 스킬을 제공하면 평가 차이로 설명한다.
- 녹딱은 고정 코스의 실제 발동 조건과 Pt를 비교한다. 시계○200012는90Pt이며 반시계 코스에서 우대하지 않는다. 팀 경기장 전체의 발동률 수치를 이 대회의 유효율로 가져오지 않는다.
- 원문이 다른 대회 재활용·본육성 전용 스탯·특정 주자의 내장 가속기를 근거로 우선순위를 바꾸는 부분은 이번 범위의 목표와 다르다. 해당 차이를 데이터 오류로 처리하거나 특정 주자 입력을 추가하지 않는다.
- JP2026 카드 중 KR미래시만 있는 카드는 한국 현시점 편성에 강제 포함하지 않는다. 해당 공략과의 카드 불일치를 출시 필터와 스킬 수급 기회비용으로 설명한다. JP 날짜를 KR 날짜로 대체하지 않는다.

## 이벤트 선택지의 실제 한계

[파인30283 카드 공략](https://kamigame.jp/umamusume/page/329645853809615942.html)은 진행3 이벤트의 상단에서 금색202761·204071, 하단에서204072·진수체210101·양의 가호210262를 제시한다. 현재 팩의 `ts-evt_30283_830283003`에도 `selection: single`과 두 선택지가 보존되어 있다. 이는 동일 육성에서 모든 보상을 동시에 확정한다는 뜻이 아니다.

카드의 잠재 수급 합집합은 여러 선택지 중 가능한 경로 집합이다. 이 합집합을 획득 보장량이나 확률로 표현하면 모델 오류다. 직접 선택지와 일반 역방향 이벤트 연결을 구분하고, 비교 보고에서 분기 미확인/배타성을 표시한다. 시나리오 링크·친구 카드의 필수성도 이 기사 하나로 게임 전체의 정밀 훈련 효과가 검증됐다고 처리하지 않는다.

## 병행 보강: 한국 LoH

`data/curated/p4-loh-evidence.json`에 공식 근거1건을 추가했다. [카카오 공식 도움말](https://kakaogames.oqupie.com/portals/1576/articles/65213)과 [공식 채널의 2026-09-09 게시 목록](https://pf.kakao.com/_DzxjIb/posts)을 함께 확인했다.

2026년9월12일12시 메인 시작, 오이 더트2000 우·봄·밤, 출전12명이다. 날씨·주로는 무작위이므로 확정값을 넣지 않는다. 도움말 본문은 월/일만 적고 실제 갱신일을 표시하지 않아, 연도는 공식 채널 게시 문맥으로 보완했다. 개별 게시물 URL은 확보하지 못했으며 확인일과 실제 갱신일을 구별한다. 전체 한국 LoH 연표의 완성은 아니다.

[2026-08-27 개인 LoH 공략](https://swallow91.tistory.com/592)은9/15~24로 적어 공식9/12~21과 다르다. 공식 시각을 사용하고 이 차이는 일정 자료 오류로 남긴다. 같은 코스라고 챔미9인 순위 조건을 LoH12인에 그대로 적용하지 않는다.

이번 조사에서 전제·작성 시점·서버가 명확한 정밀 마신/유효율 실측값은 추가 인증하지 않았다. 원본 연구행 수를 새 실측 사례 수로 계산하지 않으며, 마신 수치를 만들지 않는다.
