`ReferencePage.tsx`에서 자동 배분 패널·상태·이벤트를 제거하고, 전용 UI 컴포넌트와 깊은 캐릭터 갤러리를 삭제했다. 전용 확장·2열 CSS도 제거했다. `UnifiedLineageTree.tsx`는 같은 컨테이너 안에서 내부 캔버스·스크롤·확대를 유지하며, 모브의 카드 선택창으로 새 계획 인자를 3성으로 입력한다. 기존 실제 1·2성은 보존한다.

`domain/lineage.ts`는 V1 필드 형태를 유지하면서 모브 계획의 고정을 허용한다. `lineage-validity.ts`, `lineage-evaluation.ts`, `plan-comparison.ts`는 과거 하위 캐릭터 정보를 동일 캐릭터·출시·적성 기준으로 사용하지 않는다. 상위 7인의 중복 제한·상성 계산은 유지한다. `png-export.ts`는 상위 7인만 초상화를 출력하고, 하위 24인은 모브·적인자·연결선을 출력한다. 원본 ID·UUID·혈통·실제 기록은 JSON과 PNG 감사 데이터에 그대로 보존한다. 서포트 추천·7인 배치 알고리즘·V1 형식·이미지 권리 게이트는 변경하지 않았다.

집중 단위 14건(새 검증 4건과 관련 계보 구조·잠금 10건), PC/모바일 핵심 4건을 통과했다. 실제 로컬 DB의 7인 입력에서 상성 159점, 모브 24칸 편집·고정·해제·전환·복원, 7인 배치 미리보기·취소·적용을 확인했다. 기존 `31-node-example.json`도 내보낸 입력 전체가 동일했고, 명시적 편집 후에도 31개 UUID·백인자·기존 캐릭터·부모 연결이 유지됐다. 기존 1·2성 인자는 종류를 바꿔도 해당 별수를 유지했다.

타입 검사·lint·빠른 프로덕션 빌드(`npm --ignore-scripts run build`, 데이터 전체 재검증 훅 제외)를 통과했다. 전체 단위/E2E·벤치마크·P9 배포는 실행하지 않았다. 초기 브라우저 검증의 저장 화면 왕복 후 접힌 계보를 펼치지 않은 테스트 탐색 오류를 수정하고 재확인했다.

남은 범위: P9 전 전체 회귀와 실기기 검수. 과거 자동 배분·깊은 캐릭터 선택을 기대하는 기존 E2E 시나리오는 변경된 수동 UX에 맞춘 갱신이 필요하며, 이번 집중 검증 통과를 전체 회귀 통과로 간주하지 않는다. 7인/서포트 PNG 전체 재검증과 공개 배포 검토도 이번 범위에 포함하지 않았다.
