2인·3인 상성은 해당 일본 자료의 공통 그룹 교집합을 직접 계산한다. 그룹 소속 7,788행과 명시 가중치 189개, 기본 가중치 1, 동일 인물 포함 시 원자료의 0 정책을 보존한다. 세 사람 공통 그룹은 2인 점수의 합으로 복원하지 않는다.

정적 기본 상성에 들어 있는 레이스 분류 그룹을 일괄 제거하지 않는다. 이는 사용자가 입력하는 중상작 우승/G1 보너스와 별개다. 이번 코드에는 중상작 기록·가산 입력이 없다.

자료에는 독립적으로 확인된 7인 공식이 없다. 따라서 7인 합산과 점수 순위는 **기본 차단**한다. 사용자가 `검증 전 참고 합산으로 후보·배치 비교`를 켠 경우에만 `2인 관계 3개 + 3인 관계 4개`라는 **가정**의 합계·기여값으로 비교한다. 확정 기본 상성이나 한국 최적 배치로 표시하지 않는다. 6배치는 부모/대상 고정, 조부 형제 순서 중복 제거, 인자 동반 이동을 유지한다.

빨간 인자 규칙의 독립 기대값도 없으므로 실제 원자료에는 기존 가상 보정표를 적용하지 않는다. 현재 화면은 원자료 초기 적성과 계획한 인자 별수 합계를 표시하고, 보정 후 등급 계산은 검증 대기로 둔다. 기존 가상 화면의 적성 계산은 회귀 검증용으로 계속 동작한다.
