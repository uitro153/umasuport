# 실제 데이터의 부족·연결 시점

## P8.7 현재 표시·검색 범위

이번 변경은 사용자 흐름과 개인 환경설정이다. 게임 데이터·계산식·한국 서버 적용 인증을 추가 확보한 것으로 보지 않는다. 사용자 검색은 이름·별칭만 사용하며 DB ID는 검색 대상에서 제외한다. 일반 UI의 장문 기술 검증 패널은 제거하되 한국 적용 미확인·예상 일정·연결 미확인 안내와 내부 출처 기록은 유지한다. 일부 한국어 명칭이 없으면 제공된 일본어 명칭을 사용하고 임의 번역하지 않는다.

빠른 선택 목록은 계획과 별도로 브라우저에 저장되며 P8 V1이나 실제 인자의 소유 기록을 확장하지 않는다. 이미지 공개 권리 838개 ID는 계속 pending이다. 실제 회귀와 보안 점검의 한계는 [P8.7 보고서](P87_USER_FLOW_VALIDATION.md)를 따른다. 아래 P8.6 이력의 ID 검색·기술 상세 안내는 현재 일반 UI의 동작이 아니다.

## P8.6 현재 범위 · 2026-11-05

**공개 이미지 재배포 허가는 승인0/보류838개 ID**다. 로컬 기술 검증 성공을 허가 완료로 승격하지 않는다. 전체 보류 ID와 사유는 `data/assets/p85-public-release-blocked.json`에 보존했다. 이는 한국 출시 미확인·백인자 자격·계산 정확도와도 다른 상태다. 사용자의 별도 허가 문서가 없으므로 이미지 파일은 `data/local/p85-assets/game-assets/`에만 두고, 일반 production resolver와 `dist`는 미승인 이미지를 제공하지 않는다. private build는 명시적으로 `.preview/p85-private-static`에만 생성한다. 공개 배포와 권리 검토는 P9에서 별도로 판단하며 자동 공개하지 않는다.

## P8 당시 범위 · 2026-11-05

계획 저장·복원과 JSON/PNG 출력은 별도의 사용자 데이터 계층이며 추가 게임 데이터를 추정하지 않는다. 저장 당시 결과는 참고값이고 현재 데이터로 다시 계산한다. 한국 상성 실측·백인자 자격 직접 인증·한국 적용 정량값의 기존 공백은 그대로다. 인자 교체 후 혈통 확인은 사용자의 기록 확인이며 게임 실물 인증이 아니다. P8 당시 출력은 이름·ID 중심이었고, P8.5에서는 위 비공개 이미지 계층을 추가했다. 저장소의 브라우저/프로필별 분리·사용자 삭제에 대비해 JSON 백업을 제공하며 클라우드 동기화는 없다. 전체 자료의 정적 배포·로딩과 호스팅 검증은 P9로 이관한다. [P8 보고서](P8_PERSISTENCE_EXPORT_VALIDATION.md) 참조.
