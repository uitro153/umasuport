# P3 대회별 스킬 평가·본육성 서포트 분석

확인일: 2026-11-05 · 작업 경로: `C:\dev\UMA`

## 구현과 실행

기존 P0 데이터 계약, 가상 회귀, P1 공개식, P2 31인 소유·혈통 모델을 유지했다. P3는 별도 `uma-p3-skill-support` 계약과 순수 평가 엔진으로 연결한다. 개발 서버에서 상단 **스킬·서포트 분석** 또는 `/?view=skills`로 연다. 계보와 독립 실행되며 화면 왕복 시 계보와 본육성 편성을 메모리에 보존한다. 새로고침 저장은 이번 범위가 아니다.

입력은 대회·각질·인자작 시나리오·추천 성향 드롭다운과 본육성 서포트 최대 6장·돌파 0～4다. 출전 우마무스메·3인 팀·자동/수동 인자작은 입력받지 않는다. 일반 힌트, 이벤트, 금색 스킬을 통한 하위 스킬 경로를 구분한다. 같은 스킬을 본육성에서 얻을 수 있어도 추가 힌트 후보로 유지한다. 시나리오 선택이 미검증 훈련 효과나 링크 카드 보너스를 만들지는 않는다.

```powershell
cd C:\dev\UMA
npm.cmd run data:import:p3
npm.cmd run dev
```

입력 경로를 바꾸려면 `data:import:p3 -- <uma_db 경로> <data-integration 경로>`를 사용한다. 원자료를 읽기 전용으로 확인하고 `data/local/`에 출력한다. 서버 DB와 비밀 키는 필요하지 않다. 실제 전체 자료는 정적 빌드에 자동 포함하지 않는다.

## 평가 정책과 실제 검증

조건식의 AND/OR·괄호를 보존해 거리 구분·마장·방향·계절·날씨·주로·각질을 판정한다. 순위·전개·능력치 조건은 조건부, 미지원 변수는 미검증으로 둔다. 정적 불일치가 있으면 다른 미확인 조건 때문에 유효해지지 않는다. 효과를 해석하지 못한 경우에도 핵심 가치로 확정하지 않는다. 상대 디버프의 음수 효과를 자기 능력 감소와 혼동하지 않는다.

등급은 사용자 우선순위를 표현하는 정성 정책이다. 전제 포함 기본 Pt **110 이하**는 저비용, **160 이상**은 고비용으로 구분한다. 마신/Pt의 정밀 비율이나 게임 내부 공식이 아니다. 스피드·스태미나 녹딱은 실제 발동 조건이 맞을 때 우대하며 능력치 등 추가 조건은 그대로 표시한다. 다른 주자의 가속기 중복 추정으로 감점하지 않는다. 핵심 가속은 구간 검증 전까지 검토 후보로만 표시한다.

| 실제 레코드·입력 | 결과 |
|---|---|
| 시계 방향○ 200012, 90Pt | 우회전 MILE/LONG에서 우선 확보, 좌회전 CLASSIC에서는 비해당 |
| 반시계 방향○ 200022, 90Pt | 좌회전 CLASSIC에서 우선 확보 |
| 봄 우마무스메○ 200172, 90Pt | 봄 조건에서 스피드 녹딱 우대 |
| 자신감 202652, 180Pt | 능력치 조건을 유지하며 고비용 부가 확보 |
| 시계 ○ / ◎ / 귀신 | 원시 비용과 전제 참고 합계 구별: 총 90 / 200 / 330Pt |

마신 이득과 발동률은 모두 `null`이다. 실측값을 만들거나 백인자화 확률을 곱하지 않았다. 결과는 실제 원자료·조건식과 정성 정책의 회귀 검증이며, 독립적인 KR 게임 실측 검증은 **0건**이다. JP/KR 오버레이가 다른 경우 상세 화면에서 평가에 사용한 그룹과 JP 원문을 분리한다. 과거 대회 조건에 현재 스냅샷을 대입한 연구 평가이며 과거 한국 패치 재현 인증은 아니다.

## 남은 데이터와 다음 단계

스킬 비용 미확인은 전체 1,028개이며 이 중 일반/금색 38개다. 고유·진화처럼 원래 비용이 없는 항목과 누락을 섞어 비용 0으로 바꾸지 않는다. 조건 그룹 없는 3개, 미해석 효과/변수, 스킬별 한국 출시일·적용 패치, 서포트 558장의 일정, 시나리오 한국 일정, 정밀 마신·유효율 근거를 보충해야 한다. 소유 카드가 제거된 이벤트 본문은 억지로 카드에 연결하지 않았다. 시나리오 고유 수급·링크 효과는 추가 검증 전이다.

현재 P3의 실제 데이터 연결·정성 평가·본육성 6장 경로 분석은 사용할 수 있다. 한국 전체 데이터 완전성·정밀 게임 정확도 완료로 판정하지 않는다. 다음 구현 단계는 별도로 요청할 P4 인자작 6장 조합 최적화·종마 후보이며 이번에는 구현하지 않았다. G1 가산, 육성 체급/완주율 시뮬레이션, 백인자화 확률도 추가하지 않았다.
