## 우월성 판정과 전체 스킬 차집합

현행 [상태 비교 함수](../src/engine/support-deck-optimizer.ts)의 순서는 **맞춤 합계 → 우선 녹딱 수 → 공략 참고 주요 목표 → 과다SR 불이익 → 성향별 구성/중복 → ID**다. 균형 성향에서는 중복을 줄이는 쪽을 먼저 본다. 전체 녹딱 개수는 이 동률 순서의 독립 키가 아니다.

## 탐색 누락 검사와 알고리즘 조치

1. **표준 P6 재실행:** 기본96장+지정 공급자34장=130후보, 빔80, 상태100,000, 이벤트 계획32개에서 B를 다시 선택했다. 39,184상태·완성8,563개를 확인했고 상태 한도는 닿지 않았으나 빔은 가지치기했다.
2. **공급자 확장:** A의 목표 공급자10005·30159가 후보 공급자 목록에 있으며 추가 공급자 목록에는 없으므로 초기96장에 이미 포함됐다. B의30107은 확장으로 추가됐다. 지정 공급자를 빼고 B만 허용한 비교가 아니다.
3. **이벤트 계획 한도:** A와 B 고정6장에서32→256으로 늘려도 점수·전체 스킬·선택 이벤트 계획이 같았다. 두 편성에서 `eventPlansPruned:false`여서 해당32개 제한이 차이의 원인이 아니었다.
4. **A∪B 전수:** 합집합11장의 모든6장 조합 `C(11,6)=462`를 같은 조건으로 전수 평가했다. 현행 모델링·이벤트 계획 선택 정책에서 B가382점과 같은 동률 키로 우승했다. 빔·후보·이벤트 계획의 각 탐색 한도에 따른 가지치기 없이 A를 포함한 카드 조합을 모두 비교했다. 내부의 부분집합 우월 제거·동일 커버리지 중복 제거는 유지되므로 원문에 존재하는 모든 이벤트 옵션을 별도로 전수 나열했다는 뜻은 아니다.
5. **필수 DP:** 표준 요청은87상태에서 실제 수급 증거를 찾았고 그 한도에 닿지 않았다. DP 증거는 완성 편성 보관으로 연결되며 반환된 B의 필수 목표도 실제 계획으로 재확인했다. 고정6장 검사에서 보조DP가 작은 예산에 닿더라도 별도6장 전수평가가 수행되므로 이를 목표 불충족이나 전역 불가능의 증거로 사용하지 않았다.

A가 더 우월한데 누락됐다는 전제가 성립하지 않아 A의 각 빔 prefix 제거 이력을 추가 계측하거나 검증용 초기 해를 운영 엔진에 넣지 않았다. 기존 중복 동률 정책을 전체 녹딱 개수 우선으로 바꾸거나 특정6장을 맞추는 가중치를 추가하지 않았다. **알고리즘 변경은 없으며, 변경 전·감사 후 표준 추천은 모두 B / 374+8=382 / 목표48 / 녹딱8이다.**

## 전역 인증 범위와 남은 한계

- 확정한 범위: A/B의 최신 동일 조건 재평가, 알려진 수급 경로·제약의 적격성, 현재 동률 정책의 B 우위, 현행 모델링·이벤트 계획 선택 정책에서 A∪B11장462조합 안의 최적성, 두 실제 대회 표본에서의 확대 탐색 일치.
