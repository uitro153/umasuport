# 한국 서버 우마무스메 인자작 도구 — Codex 인계 패키지

**문서 버전:** v1.0 · 2026-11-04  
**상태:** 구현 착수용 요구사항/개발계획. 코드·게임 데이터·실제 게임 이미지의 수집/배포는 아직 수행하지 않음.

4. `04_UI_ASSET_SPEC.md` — 데스크톱·모바일 와이어프레임, 캐릭터 이미지 규격·자산 규정

## 절대 변경하지 말아야 할 사용자 결정

- 한국 서버 기준, 일본 서버의 데이터는 한국 출시 시점에 맞춰 투영.
- **계보 도구 주기능**: 기본 7인, 상세 31인. 중상작 이전 **기본 상성** 계산만.
- 인자 자동 배분: 조부모의 중상작 적성 우선, 유전자작은 선택; 조건 무손실이면 12성, 아니면 6성; 혈통 집중 우대.
- **서포트 추천**: 해당 대회·각질의 여러 육성마가 공통으로 활용할 백인자 확보가 기본. 다른 대회 재활용률을 기본 보상으로 주지 않음.
- 스킬 평가: 마신 효율·유효율·스킬Pt 효율 + 핵심성, 저비용 스피드 녹딱 우대, 스태미나 녹딱 적극 고려, 고비용 패시브 후순위.
- 한 카드가 이미 확보한 스킬만 재제공하면 신규 스킬 가치 0; 신규 고가치 스킬 우선. 과도한 SR 편성만 가볍게 경계.
- 출전 주자 3명 선택·내장 스킬 입력·자동/수동 인자작 선택·정밀 훈련 체급 시뮬레이션·인자화 확률 곱셈 최적화 **금지**.
- **미래 대회 선택 시 해당 대회 기준 출시 콘텐츠 포함**, 현재 기준 전환 제공; 예측 일정에는 미래시 표시.
- 공개 원본 사이트의 코드·UI·이미지 파일을 라이선스 확인 없이 복제하지 않음.

## 상태 정의

- **확정**: 사용자와의 대화로 합의된 기능·원칙.
- **구현 선택**: 동일 요구를 만족하는 기술적 권장안. Codex가 필요하면 변경 가능하되 이유 기록.
- **검증 데이터**: 수치·상성표·인자 규칙 중 공식/검증 출처가 확보되어야 계산에 반영할 항목.

관련 문서의 예시 ID, 카드명, 날짜는 전부 예시로 표기하며 실제 한국 서버 데이터로 취급하지 않는다.
