# Codex에 그대로 전달할 시작 지시문

이 저장소의 `docs/01_REQUIREMENTS.md`, `docs/02_IMPLEMENTATION_PLAN.md`, `docs/03_DATA_ACQUISITION.md`, `docs/04_UI_ASSET_SPEC.md`를 먼저 읽어라. 이 문서들은 사용자와의 반복 논의를 거쳐 확정된 요구사항이다. 문서 내용과 모순되는 임의 기능을 추가하지 마라.

## 우선 구현 범위

1. **P0**: TypeScript+Vite+React 골격, `src/domain` 엔터티, 한국 서버 출시/미래시 데이터 필터, 검증 가능한 샘플 JSON fixture, unit tests.
2. **P1**: 7인 계보 UI와 **중상작 전 기본 상성** 계산, 빨간 인자에 따른 적성 정보 표시, 6개의 조부모 배치 탐색, 모바일 레이아웃.
3. 샘플 게임 수치가 검증되지 않은 상태라면 실제 정확도인 척 가짜 수치를 넣지 말고 `fixture`임을 눈에 띄게 표시하라.
4. 사용자에게 재요청하지 말고, 확인이 필요한 원본 상성/인자/한국 서버 출시 데이터를 `docs/DATA_GAPS.md`에 기록하라.

## 금지 사항

- G1 중상작 보너스 계산, 3인 출전팀 입력, 자동/수동 인자작 선택, 완주율·훈련 체급 시뮬레이션, 인자화 확률을 가중치에 곱하는 모델을 추가하지 말 것.
- '범용'을 다른 대회 재사용으로 해석하지 말 것. 이는 **해당 대회·각질 여러 육성마에서 공통 활용**이라는 뜻이다.
- 한국 출시일 대신 Global 출시일을 사용하지 말 것. 대회를 선택하면 **대회 시작 시점 기준** 출시된/예상된 콘텐츠를 보여주며, 예측은 구별하라.
- 참고 사이트 코드나 이미지의 허가 없는 복제·재배포 금지.

## 작업 보고 형식

- 구현한 요구사항 ID
- 수정/추가 파일
- 실행한 테스트와 결과
- 미구현 범위·데이터 공백
- 다음 단계 착수에 필요한 조치

기능이 충분히 동작할 때마다 실제 브라우저에서 데스크톱 1440px, 모바일 375px를 검수하라. 품질과 테스트를 통과한 범위만 '완료'로 보고하라.
